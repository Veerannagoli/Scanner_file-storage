# 🔒 Secure Scanner File Storage

A secure web application that allows users to upload files and access them through a unique QR Code. Anyone can scan the QR code, but only users with the correct password can view or download the stored files.

## 🌐 Live Demo

👉 https://scanner-file-storage-1.onrender.com/

---

# 📖 Overview

Secure Scanner File Storage is designed to make file sharing simple and secure.

Instead of sending files directly, users upload them to the system, generate a QR code, and share the QR code. Anyone can scan the QR code, but access to the files is protected using the owner's password.

This provides an extra layer of security while making file sharing quick and convenient.

# 🚀 How It Works

### Step 1
Create an account by entering:

- Name
- Password

### Step 2

Login to your account.

### Step 3

Upload one or more files.

### Step 4

Generate your personal QR Code.

### Step 5

Share the QR Code with anyone.

### Step 6

When someone scans the QR Code:

- The storage page opens.
- The system asks for the password.
- If the password is correct, all uploaded files become accessible.
- Otherwise, access is denied.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Secure-Scanner-File-Storage.git
```

Move into the project

```bash
cd Secure-Scanner-File-Storage
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
